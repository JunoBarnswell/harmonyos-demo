# 验收清单

## 交付环境已检查

- 配置文件均可解析。
- 应用和模块资源引用均可解析到对应文件或资源定义。
- `EntryAbility` 源码、注册页面和加载入口均存在且一致。
- Stage 入口、产品与模块目标配置一致。

## 需在 DevEco / 设备完成

以下均为待执行项，不应视为已通过。

| 操作 | 预期 |
| --- | --- |
| 同步项目并 Build HAP | 无 ArkTS / 资源 / SDK 构建错误 |
| 启动应用 | 进入首页，无白屏或崩溃 |
| 点击 +1 三次，再重置 | 数字依次到 3，再到 0 |
| 打开开发指南并返回 | 展示指南内容，返回后保留计数器状态 |
| 切换待办 | 显示两条示例，完成一条 |
| 输入空格并添加 | 提示输入内容，不新增记录 |
| 输入中文或英文，点击添加或键盘提交 | 新记录出现，输入框清空 |
| 勾选和取消勾选 | 完成数、删除线同步变化 |
| 删除全部待办 | 显示空态，允许再次添加 |
| 输入超过 60 字 | 输入受最大长度约束 |
| 添加到 100 条后再次添加 | 提示上限，删除后可继续添加 |
| 长标题和多条待办 | 标题换行，列表可滚动，删除按钮可操作 |
| 杀掉进程后重新启动 | 恢复两条初始待办及计数器 0 |
| 系统返回键/手势 | 指南返回主页，根页面按系统默认行为退出 |
| 手机竖屏、平板、横屏和大字体 | 核查可见性、滚动与点击范围；按设备测试结果调整 |
